# library/data/ — static lookup tables

Small JSON tables inlined into any bundle that imports them (eager JSON imports, no runtime fetch).
Import as `@map/data/<file>.json`.

- **`langFamilyByLanguage.json`** — language label → family (`"Telugu": "Dravidian"`). Derives
  `languageFamily` when the API returns `null` for `imb_language_family`. English labels only.
- **`langFamilyByIso.json`** — ISO 639-3 code → family (`"afr": "Indo-European"`). Used first,
  because the API localizes language labels but `primary_language.value` (the ISO code) is stable
  across locales. Generated by joining `langFamilyByLanguage.json` onto EN API rows by ISO code;
  there is no regeneration script — re-run that join against a fresh EN pull if the language set
  changes.
- **`iso-numeric-to-alpha2.json`** — ISO 3166-1 numeric → alpha-2 (`"840": "US"`). For joining
  numeric-keyed geodata (world-atlas TopoJSON) to alpha-2 records. No code consumers yet — kept as a
  ready lookup.

Consumers of the language tables: `composables/useMapData.js`, `useDoxaSearch.js`, `useMapLayers.js`,
`legends/useLanguageFamilyLegendData.js`.
