people-groups-grid · staging

Capability 2 — a COPY of the DX-life people-groups grid (UupgsList.vue) migrated into an OWNED custom element <people-groups-grid>: fuzzy search + four dropdowns (Region / Block / People-Group / Religion) + faceted counts. Its own controls can be turned off (show-search="false" / show-filters="false") so a parent header drives it via props; it emits groups-filtered both as a Vue event and a native bubbling CustomEvent. Data is fetched from the injected pray-base-url (default https://pray.doxa.life) — no Nuxt context required.
