# public/ — the built output

This folder is GENERATED by `bun run build`; do not edit it by hand. It holds exactly one thing:

- **`dx-maps/`** — the output folder: 30 plugin bundles and 45 pages, self-contained.
  Copy this one folder to any web host (or open it from disk) and it works.
  - `dx-maps/index.html` — the front page: the Plugin Studio, every plugin in one place.
  - `dx-maps/<plugin>/<plugin>.js` — a plugin's bundle (a custom element; load it with a `<script>` tag).
  - `dx-maps/<plugin>/<page>/index.html` — a ready-made page for one plugin view (embed it in an `<iframe>`).
  - `dx-maps/manifest.json` — every plugin, page and embed snippet, machine-readable.
  - `dx-maps/assets/` — the data, fonts and images the plugins fetch at runtime.

The folder's name comes from `name` in `vite.doxa-maps-build-config.json`. Sources live in
`plugin-designs/`, `library/` and `data/`; `rm -rf public/ && bun run build` recreates all of this.
